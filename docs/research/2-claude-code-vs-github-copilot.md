# Claude Code と GitHub Copilot の比較調査レポート

**調査日**: 2026-07-28  
**対象 Issue**: #2

---

## 1. 製品概要・位置づけ

### Claude Code

- Anthropic が開発・提供する公式 CLI ツール（デスクトップアプリ・IDE 拡張も提供）
- 単なるコード補完ではなく、**AI エージェント**として機能することが特徴
- ファイル読み書き・ビルド・テスト・デプロイなどをローカル環境で自律実行できる
- エンタープライズ向けの自動化・エージェント機能を標準提供

### GitHub Copilot

- Microsoft・OpenAI・GitHub が共同開発した AI コーディング支援ツール
- **IDE 内でのコード補完・チャット**が主軸
- 個人開発者から enterprise まで幅広い層をターゲット
- GitHub リポジトリとネイティブに統合されている

---

## 2. 主な機能の違い

| 機能 | Claude Code | GitHub Copilot |
|------|------------|----------------|
| コード補完（行単位・低レイテンシ） | △ | ○○ 主機能 |
| チャット UI | ○ | ○○ 充実 |
| プロジェクト全体の理解（大コンテキスト） | ○○ | ○ 限定的 |
| ファイルの自動編集・生成 | ○○ 標準 | ○ 限定的 |
| テスト自動実行 | ○○ 標準 | ○ 拡張機能として |
| エージェント（自律実行） | ○○ 主軸 | △ 試験的 |
| マルチエージェント・並列実行 | ○○ | × なし |
| MCP（Model Context Protocol）統合 | ○○ 標準 | ○ 限定的 |
| GitHub との深い統合 | ○ | ○○ ネイティブ |
| PR レビュー支援 | ○ | ○○ |
| クラウド実行 | ○ オプション | × なし |

## 3. 対応環境・インテグレーション

### Claude Code

- **CLI**: macOS, Linux, Windows（WSL2）
- **デスクトップアプリ**: macOS, Windows, Linux（ベータ）
- **Web**: ブラウザベースのクラウドセッション
- **IDE**: VS Code, JetBrains（IntelliJ, PyCharm, WebStorm 等）
- **CI/CD**: GitHub Actions, GitLab CI
- **クラウド**: AWS Bedrock, Google Vertex AI, Azure Foundry
- **Slack**: Claude Tag によるスラック内セッション実行

### GitHub Copilot

- **IDE**: VS Code（最も手厚い）, JetBrains, Visual Studio, Neovim
- **Web**: GitHub.com のコードエディタ
- **CLI**: Copilot CLI（試験的）
- **プラットフォーム**: Windows, macOS, Linux（IDE 経由）
- **拡張性**: Copilot Extensions（試験的）で外部サービス連携

## 4. コスト・料金体系

### Claude Code

| プラン | 月額 | 主な対象 |
|--------|------|---------|
| Claude Pro | $20 USD | 個人（制限付きアクセス） |
| Claude for Teams | ユーザー単位 | チーム向け、CLI・Web セッション含む |
| Claude for Enterprise | カスタム | SSO・SLA・サポート込み |
| API（従量課金） | トークン単価 | 開発者・企業 |

- Claude Sonnet 4.5: 入力 $0.003/1M トークン、出力 $0.015/1M トークン（目安）
- プロンプトキャッシングで最大 90% コスト削減可能

### GitHub Copilot

| プラン | 月額 | 主な対象 |
|--------|------|---------|
| Individual | $10 USD（年額 $100） | 個人 |
| Business | $19 USD/ユーザー | 企業（管理機能付き） |
| Enterprise | カスタム | 大規模企業、SSO・監査ログ込み |
| Free | 無料（制限付き） | 試用 |

- 定額制のため使用量に左右されない点がコスト予測しやすい

## 5. ユースケース別の使い分け

| ユースケース | 推奨 | 理由 |
|------------|------|------|
| IDE 内でのリアルタイム補完 | **Copilot** | 低レイテンシ、入力中の即座提案が強み |
| 個人開発・学習・プロトタイピング | **Copilot** | 月 $10 の低コスト、使いやすい UI |
| GitHub ワークフロー中心の開発 | **Copilot** | PR レビュー・Issue 連携がネイティブ |
| 複雑な自動化・エージェント作業 | **Claude Code** | ファイル操作・テスト・ビルドを自律実行 |
| CI/CD パイプラインの自動化 | **Claude Code** | GitHub Actions・MCP と深い統合 |
| 大規模リファクタリング | **Claude Code** | 大コンテキスト（最大 1M トークン）で全体把握 |
| マルチエージェント協調タスク | **Claude Code** | 並列エージェント、チーム機能が標準 |
| エンタープライズ・高セキュリティ環境 | **Claude Code** | ZDR、SSO/SAML、詳細な権限管理 |
| 外部 DB・API との連携自動化 | **Claude Code** | MCP で柔軟に外部ツール統合 |
| 教育・コードリーディング支援 | **Copilot** | コミュニティが大きく、学習ドキュメントが充実 |
| ハイブリッド利用 | **両方** | 補完は Copilot、自動化は Claude Code と役割分担 |

## 6. 得意・不得意まとめ

### Claude Code

**得意**
- ファイル・ディレクトリ操作の自律実行
- テスト実行・デプロイなどのワークフロー自動化
- 大規模コンテキストを活かしたプロジェクト全体の理解
- MCP を通じた外部ツール・データベース統合
- マルチエージェント・並列実行
- エンタープライズ向けセキュリティ（ZDR、SSO）

**不得意**
- リアルタイムのインライン補完（レイテンシが Copilot より高い）
- IDE 内 UX の細かな使い勝手
- 個人開発者向けの低コスト展開
- 学習曲線が Copilot より急

### GitHub Copilot

**得意**
- キー入力中の即座・低レイテンシなコード補完
- IDE 統合の洗練された UX
- GitHub ネイティブな PR レビュー・Issue 連携
- 低コスト・使いやすさ・学習コストの低さ
- 幅広い IDE 対応（VS Code, JetBrains, Visual Studio 等）

**不得意**
- 自律的なファイル操作・エージェント実行
- 複雑な CI/CD 自動化
- MCP などの高度な外部ツール統合
- 大規模コンテキストでのプロジェクト全体把握
- マルチエージェント協調

---

## 7. まとめ

Claude Code と GitHub Copilot は**競合関係ではなく補完関係**と捉えると整理しやすい。

- **「書く」をサポートしたい** → GitHub Copilot（補完・チャット・コードリーディング）
- **「動かす・変える」を自動化したい** → Claude Code（エージェント・自動実行・MCP）

実際には両方を組み合わせて使うハイブリッド戦略が、現時点では最もコストパフォーマンスが高い。ただし AI ツールの進化は速く、両製品ともアクティブに機能拡張を続けているため、定期的な再評価が必要。
